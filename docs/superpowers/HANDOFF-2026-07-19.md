### 2. War Room (commit `0ba076f`)
Specialists debate a contested question in turns inside the Interrogation Room.
Key design choice: debate turns are ordinary `ChatMessage`s (respondent = agent id),
so avatars/colors/persistence came free. All client logic is in
`src/components/InterrogationRoom.tsx` (`runDebate`, `drainStream`, chips UI);
server is one new endpoint `/api/research/debate-turn-stream` (one turn per call;
client owns the round loop). The `workingSession` local variable in `runDebate`
exists because the `session` prop goes stale across `onPersist` calls mid-loop —
do not "simplify" it away.

User moderation model: finish a debate, leave War Room armed, send another message —
the next debate opens with a fresh transcript seeded by that question. Per-turn
mid-debate interjection was deliberately NOT built (would need input enabled between
awaited turns).
