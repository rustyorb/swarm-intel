## 2026-10-08 (afternoon) — SCANNING — live-run shakedown: six more bugs fixed, pipeline verified end-to-end via API probes

**What happened:** Kyle ran real deep/fringe swarms against the morning's code and each run exposed a bug that predates the conditioner. All fixed and pushed (commits `e4babe2`..`5f4e5ce`):
- **Gemini 2.5 Flash via OpenRouter emits blank filler**: six of eight reports were 73-98% whitespace (a 12k-char report arrived as 1M chars; synthesis input hit 3.1M chars). `runUniversalStream` now cuts the stream once a whitespace run passes 4,000 chars and appends `OUTPUT ENDED EARLY`; `sanitizeReport()` strips filler at every consumer (synthesis, catalytic, red team, claims, interrogation) and the client strips on completion. The same flood overflowed localStorage and crashed the UI (`QuotaExceededError` inside a state updater) — history now persists via an effect with shrink-then-evict; session save retries with filler stripped.
- **Anthropic agents starved to 40 words**: Claude 5.x thinks by default and thinking + the web-search tool loop count against `max_tokens`; the old 16k cap was gone before the report began. Now role-based: agent 64k, synthesis 128k, orchestrator 16k. Opus/Sonnet 4.6+ get `web_search_20260209`; Haiku keeps the basic tool.
- **Failed searches were reported to agents as "0 raw hits"** (SearXNG down because Docker Desktop wasn't running after a reboot; Brave 429 because the free tier is 1 req/s and we fired 13 at once). Failed queries now read "SEARCH FAILED — did NOT run — not evidence of absence"; Brave runs sequentially at 1.1 s; baseline queries come from `rawTopic`, not the directive's title line.
- **Vite force-reloaded the page whenever server.ts changed**, killing the browser-driven agent loop mid-run (my edits did this twice). `vite.config.ts` now ignores `server.ts`, `runs/`, `docs/`, `*.md`.
- **Conditioner timeout**: 180 s cut off reasoning models mid-directive; now its own 480 s budget. **Synthesis echoed the directive as its title** (structure header used `topic`); now uses `rawTopic`. **Silent process exit** (Kyle's Ctrl-C to copy from the terminal): process-level crash/exit/signal logging added so it can never die without a line.
- Conditioner prompt refinements from Kyle's review: no numeric quotas on findings; coverage items are seeds with a mandatory "beyond the seeds" bullet; English only; tags only from the defined set.
**Verified (API probes, no UI, under $1):** single Haiku agent recon = 921 words clean; full recon swarm (Sonnet orchestrator+synthesis, Haiku agents, conditioner on) = 1,423-word directive, three 824-1,101-word grounded reports, 3,571-word verdict-first synthesis, one `runs/` dir, 6 min; single Haiku agent **deep** = 5,135 words clean in 111 s. Probe scripts: `scripts/agent_probe.py <provider> <model> [depth]` (one agent) and `scripts/swarm_probe.py` (full recon swarm) — run against a live dev server with `python3`; they POST initiate → agent-run-stream per agent → synthesize-stream with `settings.modelMapping` per role and print word counts, grounding, truncation markers and the `runs/` delta.
**Model guidance from today:** agents on the Anthropic path (Haiku 5.5 is enough, Sonnet 5.5 if you want more); orchestrator/conditioner Sonnet 5.5 (DeepSeek reasoner works but ~2-3 min); synthesis Kimi K3 (handled 1.6M chars of junk and still opened honestly) or Sonnet/Opus 5.5. Avoid Gemini Flash via OpenRouter for agents until the filler is understood. Opus input pricing on filler-bloated syntheses is where the $17 went.

## 2026-10-08 — SCANNING — Directive Conditioner shipped; double-synthesis and stream-truncation bugs fixed

**Why:** Kyle's best run ever (LIMEN, 2026-10-05, deep/8 agents/Red Team) used an 8k-word ChatGPT-written directive as the topic; every plain-topic run before it felt thin and over-hedged with the same server prompts. The input was the variable. Spec: `docs/superpowers/specs/2026-10-08-directive-conditioner-design.md`; plan: `docs/superpowers/plans/2026-10-08-directive-conditioner.md`.
**Done (branch `feature/directive-conditioner`, merged to main):** (1) synthesis fired twice per run — `runSynthesis` was called inside a `setSession` updater and Strict Mode double-invokes updaters; every `runs/` pair before today is that bug, not two user runs. (2) `runUniversalStream` now returns `{ truncated }`: Anthropic/OpenAI/Gemini error events throw, token-limit stops append a visible `OUTPUT TRUNCATED` marker to agent reports and syntheses. (3) Directive Conditioner: one orchestrator-role call in `/api/research/initiate` writes a LIMEN-skeleton directive; the server appends the raw input verbatim under an `AUTHORITATIVE CONTEXT` fence; result becomes `session.topic`, original kept as `session.rawTopic` (titles, history, dossier, relaunch). Toggle in the launch panel, default on; off or `priorContext` present → pass-through. Falls back to the raw topic on any failure (<300 words, missing `# PRIMARY QUESTION`, timeout, >12k-word input). (4) Synthesis structure headers use `rawTopic` — first live run echoed 829 words of the directive as its "title" before the fix. (5) Prompt conflicts resolved: search-honesty line no longer contradicts native-search instructions; fringe mode opens with the file's state instead of a verdict; VEX critiques are internal review that can be rebutted, conceded, or carried forward, never outranking sourced evidence.
**Verified:** `tsc` clean; curl to initiate with a 17-word topic → 1,387-word directive with all ten headers and the fence (36 s); toggle-off → no `directive` key; full recon/3-agent UI run → exactly one `runs/` directory, `meta.json` carries `rawTopic`, header and history show the short title, synthesis opened with a "Direct Answer & Primary Verdict" section.
**Next:** Run a real deep swarm with the conditioner on and compare against the LIMEN run — that is the test that matters. Kyle has prompt amplifiers he offered for second-opinioning the conditioner prompt (`buildConditionerPrompt` in server.ts); not yet run through them. Then decide on multi-pass synthesis (LIMEN compressed 64k agent words to 21k).
**Watch out:** the conditioner adds one orchestrator-model call (~30-40 s) per fresh run. `runs/` directories are now slugged from the short title. The conditioned topic is ~1.5-2.6k words and travels in every downstream request body; `session.topic` in localStorage grows accordingly.
