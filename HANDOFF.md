## 2026-10-08 — SCANNING — Directive Conditioner shipped; double-synthesis and stream-truncation bugs fixed

**Why:** Kyle's best run ever (LIMEN, 2026-10-05, deep/8 agents/Red Team) used an 8k-word ChatGPT-written directive as the topic; every plain-topic run before it felt thin and over-hedged with the same server prompts. The input was the variable. Spec: `docs/superpowers/specs/2026-10-08-directive-conditioner-design.md`; plan: `docs/superpowers/plans/2026-10-08-directive-conditioner.md`.
**Done (branch `feature/directive-conditioner`, merged to main):** (1) synthesis fired twice per run — `runSynthesis` was called inside a `setSession` updater and Strict Mode double-invokes updaters; every `runs/` pair before today is that bug, not two user runs. (2) `runUniversalStream` now returns `{ truncated }`: Anthropic/OpenAI/Gemini error events throw, token-limit stops append a visible `OUTPUT TRUNCATED` marker to agent reports and syntheses. (3) Directive Conditioner: one orchestrator-role call in `/api/research/initiate` writes a LIMEN-skeleton directive; the server appends the raw input verbatim under an `AUTHORITATIVE CONTEXT` fence; result becomes `session.topic`, original kept as `session.rawTopic` (titles, history, dossier, relaunch). Toggle in the launch panel, default on; off or `priorContext` present → pass-through. Falls back to the raw topic on any failure (<300 words, missing `# PRIMARY QUESTION`, timeout, >12k-word input). (4) Synthesis structure headers use `rawTopic` — first live run echoed 829 words of the directive as its "title" before the fix. (5) Prompt conflicts resolved: search-honesty line no longer contradicts native-search instructions; fringe mode opens with the file's state instead of a verdict; VEX critiques are internal review that can be rebutted, conceded, or carried forward, never outranking sourced evidence.
**Verified:** `tsc` clean; curl to initiate with a 17-word topic → 1,387-word directive with all ten headers and the fence (36 s); toggle-off → no `directive` key; full recon/3-agent UI run → exactly one `runs/` directory, `meta.json` carries `rawTopic`, header and history show the short title, synthesis opened with a "Direct Answer & Primary Verdict" section.
